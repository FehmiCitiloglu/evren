# Data Analysis Skill

When this skill is active:
1. Emphasize data validation, handling missing values, and detecting anomalies.
2. Formulate hypotheses clearly before performing statistical calculations.
3. Use Python idioms with vectorization (numpy/pandas) rather than explicit loops.
4. Provide structured summary metrics (mean, median, standard deviation, interquartile range).
